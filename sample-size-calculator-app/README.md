# A/B Test Sample Size Calculator

An automated tool for calculating the required sample size for A/B tests.

## Features
- **Binary Metrics**: Calculate sample size for conversion rates and other proportions.
- **Mean Metrics**: Calculate sample size for continuous metrics like GMV or Order Value.
- **Sensitivity Analysis**: Interactive charts to visualize how MDE affects sample size.
- **Multiple Test Groups**: Bonferroni correction for multi-arm tests.

## Installation
```bash
pip install -r requirements.txt
```

## Running the App
```bash
streamlit run dashboard.py
```
